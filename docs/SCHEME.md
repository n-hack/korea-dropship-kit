# 事業の型と運用の決まり

## 型
日本の Amazon（Amazon ビジネス）で**売れてから**仕入れる → 発送代行（HANIRO・福岡の倉庫）→ 韓国の買い手
売り場 … クーパン（主）。クーパンで出せない品は 11番街、手数料が最安なのはスマートストア（どちらも API は限定的）
在庫はどこにも置かない（発送代行の倉庫は「通過」だけ）

## なぜ韓国か
- 日本の品の人気が高く、ネットで買う割合が日本の約3倍
- 隣国なので送料が安く、届くのが早い（数日〜2週間）
- 大手モールが「海外購買代行」として無在庫の販売を認めている
- 販売者登録（書類が韓国語・細かい審査）が難しく、ライバルが増えにくい

## 何を出すか
1. 日本で売れている品（日本で無名の物は韓国でも売れない）
2. 韓国にメーカーが無い分野 … ゴルフ用品・釣り具・キャンプ用品・日本メーカーの時計・日本の工具・アニメのグッズ
3. 韓国で既に代行販売されている品（需要の証拠）を中心に。1件の値段だけで売値を決めない（複数の出品を見る）
4. 売値は5万ウォン以上だけ（それ未満は返品希望で自動返金される）。高単価ほど1件の利益額が大きい
5. 出してはいけない品は機械で外す（kc.py）… KC認証が要る品目・子ども用品・食品・医薬品・電池単体・スプレーや可燃物・日の丸や旭日や軍艦の図柄（一発停止の恐れ）・韓国ブランド・ハイブランド（クーパンは真贋の指摘3回で1か月停止）・有名人の写真・Kindle 等の Amazon 端末・ダウンロード版・モデルガン
6. 電気製品は「確かめる」扱い（韓国は220V・説明に変圧器を明記）。完全ワイヤレスイヤホン（充電ケースは補助電池扱い）とスピーカー（磁石）は航空便で送れないことがある
7. 1つの JAN に複数の商品ページがある時は、まとめ売り（セット）を優先（単品は Amazon 本体と競合する）
8. 容量・サイズ・入り数は、出品と仕入れで完全に一致させる（違うと「別の品」の申し立てで負ける）

## どう出すか
9. 出品上限（最初1万件）まで早めに埋め、反応の無い品を入れ替える。ただし一気に大量に出さない（最初1日100件・週ごとに1.5倍・同じブランドは1日10件まで）
10. 売れた分類の新着（発売日順）を毎月すぐ出す（無在庫は早く出した人が勝つ）
11. 売れた実績のある商品ページは消さない
12. 最初は利益率10%前後で数を売り、評価がついたら15%へ
13. 商品説明に必ず書く … 海外購買代行であること・届くまでの日数・関税（150ドル超は買い手負担）・自己都合返品の送料は買い手負担・電圧
14. ゲームは商品名に機種と「日本版」を入れる（旧機種は韓国版の本体で動かない）
15. 商品の属性の欄は分かる値で全部埋める（検索に効く）。推測では埋めない

## 土台の決まり
- **画像** … 出どころの分かる画像だけ使う（gazou.py）。卸の転載可・自分で撮影・許可のあるメーカー素材は使う。Amazon の商品画像はオーナーが方針を選ぶ（strict＝使わない／maker_img＝メーカー本体の出品の画像だけ／loose＝使う・指摘が来たら即取り下げ）。既定は strict
- **関税** … 仕入れ値が150ドルを超える品は、出品の時点で商品名の頭に「관세별도」、説明の先頭に関税の目安額を書き、了承の上で買ってもらう（クーパンには注文後に買い手へ連絡する口が無いため）。告知なしの出品に150ドル超の注文が来たら取り消し候補
- **仕入れ元** … 既定は Amazon ビジネス（API で買える・請求書が真贋の証拠になる）。卸（NETSEA 等）は会員登録と鍵が揃えば自動で候補に入る（消費者直送可の品だけ・3%以上安い時だけ）

## どう守るか
16. 見張り … 仕入れ元の在庫が少ない（最初は残り5点以下）・値上がりで利益割れなら出品を止める
17. モールの警告メールは放置しない … 対象を消し、消えたことを確かめる
18. 問い合わせは24時間以内に答える（販売者の点数の項目）
19. 仕入れの請求書と注文番号を全部保管（真贋の確認が来たら当日出す）
20. カード枠が足りなくなりそうなら新しい出品を止める（枠切れ＝仕入れ不能＝取り消し＝評価低下）
21. 始めたばかりが一番危ない … 取消率は期間内の注文数で割るので、注文が少ない最初ほど1件の取消が重い

## 回し続ける
22. 一度売れた品は「繰り返し売れる品」として出品を切らさない
23. 「作って放置」は失敗する … 毎週、売れた／売れない品を見て入れ替え、理由を記録する（urekata.py）
24. 季節 … 韓国は11〜2月が一番売れ、7〜8月（夏休み）と10月は弱い → 10月中に出品を埋め、11月前にカード枠を上げる

## お金
25. 物差しはオーナーの手元に残る額（rieki.py・jisseki.py）
26. 消費税の還付 … 課税事業者（原則課税・インボイス登録）なら、輸出の仕入れにかかった消費税が戻る。課税期間を短くすると回収が早い。発送代行の輸出許可書を保管。税理士に確認すること
27. クーパンの入金は月末締め・翌月20〜25日（Payoneer）。売れてから入金まで最長約55日 → カード枠はその分を見る（waku.py）
28. 利益の見込みにカードのポイントは入れない（安全側）

## 売れる割合の見積もり
- 無在庫の実務者の数字 … 出品1,000件あたり月5〜30件。韓国の実例は1万件で月51〜88件
- 最初の見積もりは月0.5%で置き、出品してから urekata.py の実測で置き換える

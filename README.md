# 韓国向け無在庫輸出キット（AI エージェント用）

日本の Amazon で「売れてから」仕入れ、韓国の通販（クーパン）の買い手に届ける事業を、AI エージェントが回すための道具一式です。

- AI エージェントは **CLAUDE.md** から読んでください
- 人間のオーナーは **docs/SETUP.md**（必要な登録）と **docs/SCHEME.md**（事業の型）を
- 動作確認 … `cd tools && bash kensa_all.sh`（最後に「落ちた部品 0本」）

鍵・台帳・個人情報は `config/` と `data/` に置き、リポジトリには入れません。
